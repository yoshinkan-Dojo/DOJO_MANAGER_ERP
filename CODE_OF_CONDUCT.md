# Code of Conduct

## Nosso Compromisso

Promover um ambiente respeitoso, colaborativo e profissional para todos
os colaboradores do DOJO_MANAGER ERP.

## Nossos Valores

-   Respeito
-   Integridade
-   Colaboração
-   Qualidade
-   Melhoria Contínua (Kaizen)

## Comportamentos Esperados

-   Comunicação respeitosa
-   Compartilhamento de conhecimento
-   Revisões construtivas
-   Cumprimento das diretrizes do projeto

## Comportamentos Inaceitáveis

-   Assédio
-   Discriminação
-   Linguagem ofensiva
-   Divulgação indevida de informações

## Aplicação

Os mantenedores poderão solicitar correções, remover contribuições
inadequadas e adotar medidas para preservar um ambiente saudável.
