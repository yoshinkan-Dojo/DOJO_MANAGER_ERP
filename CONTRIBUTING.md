# Contributing to DOJO_MANAGER ERP

Obrigado por contribuir com o DOJO_MANAGER ERP.

## Fluxo de trabalho

Branches oficiais:

-   main
-   develop
-   feature/\*
-   release/\*
-   hotfix/\*

## Commits

Utilizamos o padrão Conventional Commits.

Exemplos:

-   feat(finance): adiciona plano de contas
-   fix(auth): corrige autenticação
-   docs(readme): atualiza documentação

## Pull Requests

-   Descreva claramente a alteração.
-   Relacione issues quando existirem.
-   Garanta que o projeto compile.
-   Inclua testes quando aplicável.

## Padrões

-   Clean Architecture
-   DDD
-   SOLID
-   Código documentado
-   Testes automatizados sempre que possível
